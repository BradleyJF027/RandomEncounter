# Random Encounter

## About
Random Encounter is a simple, text-based, turn-based RPG. The goal being to climb as far down an endless dungeon as possible. You build a party of different classes to fight stronger and stronger enemies as you descend.

## Why
There are multiple reasons I'm doing this project the way I am. The primary reason I'm making this style of RPG is because its one of my favourite types of game to play, heavily inspired by Final Fantasy V specifically. Plus Game Dev itself has always interested me and I thought this would be a fun project to do in my off time. As for why C#, I wanted to pick a new language to learn as my primary experience is with Java, and I thought C# would be a better fit for a project of this style.
